# Кафе «Семейный Очаг»

Сайт семейного кафе в Санкт-Петербурге. Проект представляет собой адаптивную веб-страницу с информацией о заведении, меню, фотографиями и контактами.

## Реализовано в интерфейсе

- Адаптивное отображение на компьютерах и мобильных устройствах.
- Разделы с информацией о кафе и меню.
- Фотографии и визуальные материалы заведения.
- Контактная информация и навигация по странице.
- SEO-метаданные и структурированные данные.
- PWA-манифест и иконки приложения.

## Технологии

- HTML5
- CSS3
- JavaScript
- JSON / JSON-LD
- PWA

## Публикация

Планируемый хостинг — Yandex Cloud. Собственный домен приобретать не планируется; публичный адрес будет выбран при настройке хостинга.

## Перед запуском

Необходимо проверить и настроить адреса в SEO-файлах. Форма обратной связи обращается к серверному адресу `/api/lead`; серверная обработка заявок должна быть подключена отдельно. До этого нельзя считать отправку заявок работающей.
